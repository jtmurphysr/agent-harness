# Issue #003: apple_auth.py — JWT ES256 generation

**Labels:** `agent-task`
**Depends on:** #001 merged

---

## Intent

Implement Apple MusicKit JWT generation using ES256 (ECDSA with P-256 curve).
This is the most common point of agent failure on this project — read AGENTS.md
Warning 1 carefully before implementing.

---

## Acceptance Criteria

- [ ] JWT uses `algorithm="ES256"` — not RS256, not HS256
- [ ] Token header contains `{"alg": "ES256", "kid": KEY_ID}`
- [ ] Token payload contains `{"iss": TEAM_ID, "iat": now, "exp": now + 15777000}`
- [ ] Private key loaded from file path specified in `APPLE_PRIVATE_KEY_PATH`
- [ ] Token expiry checked before use — refreshed if within 60 seconds of expiry
- [ ] `EnvironmentError` raised loud if any required env var is missing
- [ ] Tests use a real generated EC key pair for fixture (not mocked JWT library)
- [ ] Coverage ≥ 85%

---

## Module Spec

### `auth/apple_auth.py`
```python
class AppleAuthClient:
    def __init__(self) -> None:
        """Load credentials from env vars. Raise EnvironmentError if any missing."""

    def get_token(self) -> str:
        """Return valid JWT. Regenerates if expired or near expiry."""

    def _generate_token(self) -> str:
        """Generate new ES256 JWT. See AGENTS.md Warning 1 for exact implementation."""
```

---

## Required Env Vars
- `APPLE_TEAM_ID`
- `APPLE_KEY_ID`
- `APPLE_PRIVATE_KEY_PATH` — path to `.p8` EC private key file

---

## Test Fixtures Needed

Generate a real EC P-256 key pair for tests:
```python
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.hazmat.primitives.serialization import (
    Encoding, PrivateFormat, NoEncryption
)
private_key = ec.generate_private_key(ec.SECP256R1())
pem = private_key.private_bytes(Encoding.PEM, PrivateFormat.PKCS8, NoEncryption())
```

Use this fixture to verify:
- Token decodes successfully with matching public key
- Token uses ES256 algorithm
- Expiry refresh logic triggers at correct threshold

---

## Notes

PyJWT >= 2.0 is in pyproject.toml. Use it.
The `cryptography` package provides EC key generation for test fixtures.
See `docs/setup.md` for how users provision the actual `.p8` key.

**Labels:** `agent-task`

## Intent

Implement the Apple Music API client. This module owns all retry/backoff logic —
callers never implement their own. Idempotency checks happen here.
All requests use `httpx.AsyncClient`.

---

## Acceptance Criteria

- [ ] `search_by_isrc(isrc)` — returns `str | None` (Apple Music track ID)
- [ ] `search_by_metadata(artist, title)` — returns `list[tuple[str, float]]` (id, confidence)
- [ ] `create_playlist(name)` — checks for existing playlist first (idempotency)

- [ ] `find_playlist_by_name(name)` — returns existing playlist ID or None
- [ ] All requests go through `_request_with_backoff` — see AGENTS.md Warning 3
- [ ] 429 responses trigger exponential backoff: 1s, 2s, 4s (max 3 retries)
- [ ] After 3 retries, raises `RuntimeError` with actionable message
- [ ] All HTTP calls mocked with `respx` — no real network calls
- [ ] Coverage ≥ 85%

---

## Module Spec

class AppleMusicClient:

    async def search_by_metadata(self, artist: str, title: str) -> list[tuple[str, float]]: ...
    async def find_playlist_by_name(self, name: str) -> str | None: ...
    async def create_playlist(self, name: str) -> str: ...
    async def add_tracks_to_playlist(self, playlist_id: str, track_ids: list[str]) -> None: ...
